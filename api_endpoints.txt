--------------------------------------------------------------------------------
0. Auth Controller (Authentication & JWT)
--------------------------------------------------------------------------------
- POST   /api/Auth/login
  Description: Authenticate user credentials and receive a JWT Bearer token.
  Body (JSON):
  {
    "email": "sysadmin@lms.com",
    "password": "adminpassword123"
  }
  Response Data (JSON):
  {
    "token": "<jwt_token_string>",
    "user": { ... },
    "tokenType": "Bearer",
    "expiresInMinutes": 480
  }

- GET    /api/Auth/me
  Description: Get current authenticated user profile (Requires Bearer token header).

--------------------------------------------------------------------------------
1. Users Controller
--------------------------------------------------------------------------------
- GET    /api/Users
  Description: Retrieve list of all users.
  Response: Array of User objects.

- GET    /api/Users/{id}
  Description: Retrieve a specific user by ID.

- POST   /api/Users
  Description: Create a new user.
  Body (JSON):
  {
    "RoleId": 1,
    "FirstName": "Jane",
    "LastName": "Smith",
    "Email": "jane.smith@example.com",
    "Password": "password123",
    "IsActive": true,
    "ProfilePicturePath": "/avatars/jane.png"
  }

- PUT    /api/Users/{id}
  Description: Update an existing user.
  Body (JSON):
  {
    "UserId": 2,
    "RoleId": 1,
    "FirstName": "Jane",
    "LastName": "Smith",
    "Email": "jane.smith@example.com",
    "Password": "password123",
    "IsActive": true,
    "ProfilePicturePath": "/avatars/jane.png"
  }

- DELETE /api/Users/{id}
  Description: Delete a user by ID.

--------------------------------------------------------------------------------
2. LeaveRequests Controller
--------------------------------------------------------------------------------
- GET    /api/LeaveRequests
  Description: Retrieve all leave requests.

- GET    /api/LeaveRequests/{id}
  Description: Get details of a single leave request.

- POST   /api/LeaveRequests
  Description: Submit a new leave request.
  Body (JSON):
  {
    "UserId": 2,
    "LeaveTypeId": 1,
    "StartDate": "2026-08-04T00:00:00Z",
    "EndDate": "2026-08-07T00:00:00Z",
    "TotalDays": 4,
    "Reason": "Family vacation",
    "StatusId": 1
  }

- PUT    /api/LeaveRequests/{id}
  Description: Update a leave request.
  Body (JSON):
  {
    "RequestId": 3,
    "UserId": 2,
    "LeaveTypeId": 1,
    "StartDate": "2026-08-04T00:00:00Z",
    "EndDate": "2026-08-07T00:00:00Z",
    "TotalDays": 4,
    "Reason": "Family vacation (updated reason)",
    "StatusId": 1
  }

- DELETE /api/LeaveRequests/{id}
  Description: Cancel/Delete a leave request.

3. LeaveBalances Controller
--------------------------------------------------------------------------------
- GET    /api/LeaveBalances
  Description: Get list of all leave balances.

- GET    /api/LeaveBalances/{id}
  Description: Get a specific leave balance by ID.

- POST   /api/LeaveBalances
  Description: Allocate leave balance to a user.
  Body (JSON):
  {
    "UserId": 2,
    "LeaveTypeId": 1,
    "CalendarYearId": 1,
    "AllocatedDays": 20,
    "UsedDays": 0
  }

- PUT    /api/LeaveBalances/{id}
  Description: Update a leave balance record.
  Body (JSON):
  {
    "BalanceId": 1,
    "UserId": 2,
    "LeaveTypeId": 1,
    "CalendarYearId": 1,
    "AllocatedDays": 20,
    "UsedDays": 5
  }

- DELETE /api/LeaveBalances/{id}
  Description: Remove a leave balance allocation.

    "Action": "Approved",
    "Comments": "Updated comments",
    "ActionDate": "2026-08-03T12:00:00Z"
  }

- DELETE /api/LeaveApprovals/{id}
  Description: Delete approval record.

9. Dashboard Controller
--------------------------------------------------------------------------------
- GET    /api/Dashboard/user/{userId}
  Description: Retrieve the dashboard data structured for a User/Employee role (e.g. balances, pending requests count, recent requests).

- GET    /api/Dashboard/manager
  Description: Retrieve the dashboard data structured for a Manager role (e.g. pending approvals count, employees on leave today, recent pending requests, leave type distribution).
